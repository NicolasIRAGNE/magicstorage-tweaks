# jacky's Magic Storage Tweaks

A small standalone companion mod for Magic Storage.

For now, it adds an **Include partial recipes** toggle to the Crafting Access. Turn it on to also show recipes when at least one required ingredient is stored.

## Demo

[![Demo](media/partial-recipes-demo.webp)](media/partial-recipes-demo.mp4)

The long-term goal is for these improvements to become part of Magic Storage itself. In the meantime, more small tweaks may be added here.

Requires Magic Storage v0.7.0.11.
