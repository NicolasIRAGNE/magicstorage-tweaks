# jacky's Magic Storage Tweaks

A small standalone companion mod for Magic Storage.

For now, it adds an **Include partial recipes** toggle to the Crafting Access. Turn it on to also show recipes when at least one required ingredient is stored.

The long-term goal is for these improvements to become part of Magic Storage itself. In the meantime, more small tweaks may be added here.

Requires Magic Storage v0.7.0.11.

## Français

Un petit mod compagnon indépendant pour Magic Storage.

Pour le moment, il ajoute un toggle **Inclure les recettes partielles** à l'interface de craft. Activez-le pour afficher aussi les recettes dont au moins un ingrédient requis est stocké.

L'objectif à terme est que ces améliorations soient intégrées directement à Magic Storage. En attendant, d'autres petits ajustements pourront être ajoutés ici.

Nécessite Magic Storage v0.7.0.11.
